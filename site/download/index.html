Как установить

Установка занимает меньше минуты. Windows может дважды спросить, доверяете ли вы файлу: это нормально для программы небольшого разработчика.

  1. Сохраните файл

    Если браузер пишет, что файл «обычно не скачивается», откройте меню загрузки и выберите «Сохранить», затем «Всё равно сохранить». Браузер так предупреждает о любом файле, который скачивали ещё мало раз.

  2. Запустите установщик

    При первом запуске Windows может показать синее окно «Система Windows защитила ваш компьютер». Нажмите «Подробнее», затем «Выполнить в любом случае».

    Окно появляется потому, что у программы пока нет платного сертификата подписи кода, а SmartScreen ещё не видел достаточно установок. Убедиться, что файл не подменён, можно по контрольной сумме ниже.

  3. Пройдите установщик

    Установщик на русском языке. После установки программа появится в меню «Пуск», а при работе её значок будет в трее рядом с часами.

  4. Добавьте бэкап

    Нажмите «Добавить бэкап», укажите папку, куда ваша программа резервного копирования складывает копии, и выберите, как часто её проверять. Дальше «Копия верна» проверяет папку сама и сообщает, только если что-то не так.

Проверка файла

Контрольная сумма SHA-256 скачанного файла должна совпадать с указанной здесь. Если хоть один символ отличается, не запускайте файл и напишите нам.

kopiya-verna_0.3.1_x64-setup.exe c8b8dc7d7a8975b517b29f73cbe93a14a3a9d661187fcc538662b9c25f621d85 Отчёт VirusTotal
kopiya-verna_0.3.1_x64.msi e01483e4a7a0a440ca09ef9dbea6a701c1a7f2527b04af387db931d98d61b568 Отчёт VirusTotal

Посчитать сумму можно в PowerShell, в папке со скачанным файлом:

Get-FileHash .\kopiya-verna_0.3.1_x64-setup.exe

Системные требования

Система
Windows 10 или 11, 64-разрядная
WebView2
Компонент Microsoft, на котором построено окно программы. В Windows 11 он уже есть. В Windows 10 установщик сам скачает его, если компонента нет, поэтому для первой установки нужен интернет.
Интернет
Для проверок не нужен. Нужен для активации PRO-ключа и по кнопке «Проверить обновления».
Обновления
Бесплатные. Кнопка «Проверить обновления» в программе скачивает и ставит новую версию в один клик. Перед установкой программа проверяет цифровую подпись обновления.
